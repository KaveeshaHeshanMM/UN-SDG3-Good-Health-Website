# Good Health and Well-being – UN SDG 3 Website

A multi-page website about **UN Sustainable Development Goal 3 – Good Health and Well-being**, built as our group coursework for Web Design & Development (4COSC011W) at IIT Sri Lanka.

The site talks about why health matters, shares fitness and wellness content and lets people find volunteer programs and send feedback. Everything is written in plain HTML, CSS and JavaScript – no frameworks.

## Live demo

https://kaveeshaheshanmm.github.io/UN-SDG3-Good-Health-Website/

## Pages

| Page | File |
|------|------|
| Splash screen | `splash.html` |
| Home | `index.html` |
| About us / vision | `about.html` |
| Health & fitness articles (fitness, yoga, benefits, local health, testimonials) | `content/` |
| Volunteer programs | `newvolunteer.html` |
| Feedback form (with validation) | `feedback.html` |
| Login | `login.html` |
| User profile | `userProfile.html` |
| Our team | `member.html` |
| Site map | `sitemapdemo.html` |

The `Validation/` and `validationSnapshots/` folders have the W3C validation results.

## Built with

- HTML5
- CSS3
- JavaScript

## Run locally

```bash
git clone https://github.com/KaveeshaHeshanMM/UN-SDG3-Good-Health-Website.git
```

Then open `index.html` in a browser.
